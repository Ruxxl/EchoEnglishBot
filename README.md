# Echo English — рабочий каркас

Telegram-бот + Mini App для продажи и прохождения курсов английского. Весь функционал — внутри мини-приложения (`webapp/`), бот — точка входа.

Это пилотный каркас: реально работают — бот, backend, каталог курсов из БД, и ключевая фича — **проверка голосового Reading-ответа через Gemini API**. Остальные экраны (самооценка, вступительный тест, урок, финальный результат, профиль) — интерактивный мокап на тех же данных, что в визуальном прототипе; их ещё предстоит связать с реальной логикой прогресса/БД.

## Структура

```
backend/        FastAPI: API курсов, проверка Reading-ответа через Gemini, БД (SQLAlchemy)
bot/            aiogram: бот, кнопка WebApp
webapp/         Mini App (статика, отдаётся тем же backend'ом на "/")
```

## Установка

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env   # уже создан и заполнен токеном бота — проверьте перед git init
```

Заполните в `.env`:
- `BOT_TOKEN` — уже заполнен вашим токеном из BotFather.
- `GEMINI_API_KEY` — бесплатный ключ: https://aistudio.google.com/apikey (без него голосовая проверка вернёт ошибку 503, остальное приложение работает).
- `WEBAPP_URL` — https-адрес вашего хостинга, на котором будет доступен этот backend (Telegram принимает в кнопке WebApp только https, не localhost).

## Запуск

Backend (отдаёт и API, и мини-апп на `/`):
```bash
uvicorn backend.main:app --reload --port 8000
```
Откройте `http://localhost:8000` — увидите мини-апп (без Telegram-контекста работает как обычный сайт, каталог курсов подтягивается из БД по-настоящему; запись голоса требует разрешения браузера на микрофон).

Бот (отдельный процесс):
```bash
python -m bot.main
```
`/start` пришлёт кнопку "Открыть Echo English" — но она заработает только когда `WEBAPP_URL` указывает на реальный https-адрес, где крутится backend.

## Что реально работает

- **Каталог курсов** (`GET /api/courses`) — из SQLite-базы, автосидится при первом запуске (уровни A1–C2 с программой по модулям).
- **Проверка Reading-ответа голосом** (`POST /api/test/reading-check`) — принимает аудио + текст задания, вызывает Gemini (мультимодально: аудио → транскрипция + оценка верности + фидбек одним запросом), сохраняет результат в БД.
- **Бот**: `/start` → кнопка WebApp.
- Мягкая проверка `Telegram WebApp initData` (HMAC по `BOT_TOKEN`) — если мини-апп открыт вне Telegram, пользователь считается анонимным, ничего не падает.

## Что ещё предстоит (не входит в этот каркас)

- Прохождение уроков/вступительного теста с реальным сохранением прогресса и XP/streak.
- Оплата курсов (Telegram Payments или внешний провайдер — заглушка `Payment` в `backend/models.py`).
- Сертификаты, реальный расчёт итогового балла по всем навыкам.
- Продакшен-БД (Postgres) — сейчас SQLite по умолчанию, смените `DATABASE_URL` в `.env`.
- Аудио из браузера пишется в `audio/webm` — Gemini обычно принимает этот формат напрямую, но если API будет отклонять файлы, потребуется конвертация в ogg/opus или wav через ffmpeg перед отправкой.

## Безопасность

`.env` в `.gitignore` — не коммитьте токен бота и ключ Gemini. Если токен уже где-то "засветился" — перевыпустите его в @BotFather командой `/revoke`.
